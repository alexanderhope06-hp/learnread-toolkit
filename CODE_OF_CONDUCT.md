# Code of Conduct

## Our commitment

LearnRead Toolkit welcomes everyone interested in improving tools for learning and reading on the web.

We are committed to maintaining a friendly, inclusive, and respectful community.

## Expected behavior

Community members are expected to:
- Treat others with respect and consideration.
- Welcome people with different backgrounds and experience levels.
- Give constructive feedback.
- Criticize ideas and code without attacking individuals.
- Respect privacy and personal boundaries.

## Unacceptable behavior

Harassment, discrimination, threats, personal attacks, and deliberately disruptive conduct are not acceptable.

## Reporting concerns

Report conduct concerns privately to the repository maintainer through the contact options on the maintainer's GitHub profile.

Include relevant details while respecting everyone's privacy.

## Scope

This code of conduct applies to project spaces and community interactions associated with LearnRead Toolkit.

The project maintainer is responsible for applying these standards fairly.
