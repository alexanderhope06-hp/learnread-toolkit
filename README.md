# LearnRead Toolkit

LearnRead Toolkit is an open-source JavaScript project that aims to make it easier to add learning and reading features to websites.

The project is being developed around two areas:

- **Learning:** quiz scoring, lesson progress, and educational components.
- **Reading:** chapter navigation, reading progress, and bookmarks.

The goal is to provide reusable building blocks that developers can integrate into their own applications without being tied to one framework, database, or authentication provider.

## Current status

This project is in early development.

The initial implementation includes:

- Multiple-choice quiz scoring.
- Configurable question point values.
- Reading progress calculations.
- Browser-compatible bookmark storage functions.
- Automated tests for the implemented features.

These features are an initial foundation, not a complete learning management system or reading platform.

Database integrations, authentication examples, persistent quiz history, course dashboards, chapter navigation components, and a browser demonstration are planned for future development.

## Requirements

- Node.js 20 or later.
- npm.
